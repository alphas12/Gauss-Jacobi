# Gauss-Jacobi

This repository contains an R Shiny project for the Gauss-Jacobi activity.

## Requirements

- R installed
- RStudio recommended
- The `shiny` package installed

## Setup

1. Open the project folder in RStudio or in R.
2. Install the Shiny package if it is not already installed:

	```r
	install.packages("shiny")
	```

## Run the app
Run it:

```r
shiny::runApp()
```

Or, in RStudio, click **Run App**.
